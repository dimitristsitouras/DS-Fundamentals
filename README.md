# GDS6000AOL – Data Science Fundamentals (Fall Term 2026)

This repository contains a week-by-week collection of exercises and lesson summaries for GDS6000AOL – Data Science Fundamentals, part of the online MSc in Data Science program.

The repository is organized by week and divided into two folders:
- Code: Weekly exercises and related code.
- Summary: Lesson summaries and key insights for each week.

The repository structure may be updated in future versions if needed.
